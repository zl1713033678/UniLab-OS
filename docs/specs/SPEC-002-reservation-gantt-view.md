- **原始需求描述**：
  > 在仪器详情的「使用预约」页签及全局「仪器预约管理」视图中，扩展按日/周展示的时间轴甘特图，直观呈现时段占用与快速框选预约。

---

## 1. 业务痛点与核心场景拆解
1. 当前仅能通过「几小时后开始 + 预约时长」表单提交预约，难以直观看到多台仪器或单台仪器未来一周的空闲窗口。
2. 实验员需要在时间轴上快速区分 `RESERVED`（已冻结待签到）、`ACTIVE`（使用中）与 `COMPLETED`（已结算）时段。

## 2. 设计与约束
- **数据复用**：直接基于 `/api/v1/bootstrap` 或新增轻量日期区间查询 `/api/v1/fms/reservations?from=...&to=...` 返回的 `start_time` / `end_time` 渲染。
- **Web 规范约束**：支持键盘焦点在时间槽间移动，状态色块必须配合图标/文本标签（禁止仅用颜色区分），冲突时段仍由后端事务最终拦截。

## 3. 分阶段实施路线图
- [ ] **Phase 1：后端支持按设备与时间范围筛选预约列表**
- [ ] **Phase 2：前端实现日/周时间轴甘特图组件并支持点击空白时段预填预约表单**
